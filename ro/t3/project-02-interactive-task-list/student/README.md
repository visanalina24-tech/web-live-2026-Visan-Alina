# Listă interactivă de sarcini

Rulați `npm install`, `npm start` și `npm test`. Limita implementării studentului este `public/task-view.js`.

Rulați `npm run test:browser` cu Chrome/Chromium disponibil pentru a valida frontiera reală HTTP, de module și DOM. Setați `CHROME_BIN` dacă executabilul nu se numește `google-chrome`.
